
# Lieferspatz
Lieferspatz is a simplified full-stack food delivery platform inspired by services like Lieferando and Wolt.

## How to Run the Project

### Prerequisites
- Python 3.x
- Flask
- SQLite 3.44.0

### Setup
1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/Lieferspatz.git
    ```

2. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Set up the SQLite database by using the provided SQL file:
    ```bash
    sqlite3 Project-FinalDB.db < Project-FinalDB.sql
    ```

4. Run the Flask server:
    ```bash
    python main.py
    ```

5. Access the application in your web browser at:
    ```
    http://127.0.0.1:5000
    ```
